# DICOM 三维人体模型工具

基于医学 **CT / MR** 扫描的 **DICOM 序列**，构建可在三维空间任意旋转查看的人体模型。
采用 **GPU 体绘制（volume raycasting）**，将 CT 的 **Hounsfield 单位（HU）** 直接映射为颜色，
**骨骼**与**器官/软组织**用不同颜色渲染，并支持交互式调节阈值、颜色与不透明度。

## 功能特性

- 📂 加载 DICOM 序列：支持拖入多个 `.dcm` 文件、整个文件夹，或 `.zip` 压缩包
- 🧠 自动按切片方向排序、处理层间距（含不规则间距插值）
- 🎨 传递函数分色：骨骼（象牙白）与器官/软组织（暖红）独立配色
- 🖱 三维交互：左键旋转 · 滚轮缩放 · 右键平移
- 🎛 实时调节：骨骼阈值(HU)、器官/骨骼颜色、不透明度、整体亮度、光影着色
- 🩺 **肺部病变高亮**：自动检测肺野内的磨玻璃影/结节/实变（HU + 肺野空气区域连通域分析），用**蓝色**醒目渲染，可调病变 HU 范围、颜色与不透明度
- 📐 **三正交截面视图（MPR，2×2 布局，各占 1/4）**：轴位(Z)/冠状(Y)/矢状(X) 三个切片视图 + 3D 视图，各自带进度条；切片叠加**病变(蓝)/骨骼(象牙白)彩色蒙版**，支持**鼠标点击定位切面**，十字线与 3D 彩色切面指示联动，可调窗宽/窗位
- 🧭 **任意斜位重建（Oblique）**：可开关的斜位视图，θ(方位角)/φ(极角) 两个角度实时旋转切片平面（三线性插值采样），并在 3D 视图中显示对应斜切面
- 🗂 分辨率选择：256 / 384 / 512（体数据自动降采样以控制显存）
- 🧪 内置**演示人体模型**（合成数据），无需真实 DICOM 即可体验
- 💾 一键导出 PNG 截图

## 快速开始

无需构建步骤，直接启动静态服务器：

```bash
node server.mjs
```

然后用浏览器打开 <http://localhost:8080>，点击左侧 **「加载演示模型」** 即可立即看到效果；
或拖入你自己的 DICOM 序列。

> 需要 Node.js ≥ 18。端口可通过环境变量修改：`PORT=9000 node server.mjs`。
> 也可以使用任意静态文件服务器托管本目录（如 `npx serve`、Nginx、Python `http.server`）。

## 使用说明

1. **加载数据**：点击「选择文件/文件夹」或直接拖入 DICOM 序列（`.dcm`、文件夹或 `.zip`）。
   工具会自动选择切片数量最多的序列（series）。
2. **查看**：鼠标左键旋转、滚轮缩放、右键平移，从任意角度观察。
3. **调色**：在「渲染设置」中调整：
   - **骨骼阈值 (HU)**：高于该 HU 值按骨骼颜色渲染（默认 300）。
   - **器官颜色 / 骨骼颜色**：分别设置两种组织类别的颜色。
   - **器官/骨骼不透明度**：控制各类别的半透明程度（器官默认半透明，便于观察内部骨骼）。
   - **光影着色**：开启后按密度梯度计算光照，增强立体感。
4. **分辨率**：默认 256（快速）；数据量大或追求细节时可选 384 / 512。
5. **肺部病变高亮**：在「肺部病变高亮」面板中开启/关闭，调节病变 HU 下限/上限、病变颜色与不透明度。检测逻辑见下方「技术原理」。
6. **截图**：点击「保存截图」导出当前视角 PNG。

## 技术原理

- **HU（CT 值）**：空气约 −1000，水为 0，软组织/器官约 30–80，骨骼约 300–1900。
- **体数据构建**：读取每张切片的分辨率、像素间距、图像位置/方向与像素数据，
  应用 `RescaleSlope/Intercept` 换算为 HU，按切片法向量排序，再重采样到均匀网格。
- **体绘制**：将 HU 体数据与病变掩膜上传为 GPU 3D 纹理（RG 两通道），在立方体包围盒内做**光线投射**，
  每步用 1D **传递函数**（查找表）把密度映射为 RGBA 并做**从前到后合成**；
  骨骼与器官因 HU 区间不同而呈现不同颜色，病变体素则用独立颜色覆盖渲染。
- **肺部病变检测**：从体数据六面边界做空气连通域填充得到「肺外空气」，
  肺野空气 = 空气体素且非肺外空气；再对 HU 在病变区间的体素做连通域标记，
  若某连通域与肺野空气相邻且尺寸小于阈值（默认 < 体积 1%），即判定为病变（磨玻璃影/结节/实变）。
- **光照**：用中心差分计算密度梯度作为表面法线，叠加漫反射光照。

## 常见问题

- **黑屏 / 提示不支持 WebGL**：请使用 Chrome / Edge / Firefox 等支持 WebGL2 的现代浏览器。
- **加载很慢或卡顿**：在「渲染设置」中把分辨率降到 256。
- **只想看骨骼**：把「器官不透明度」调为 0。
- **骨骼与器官分界不理想**：调节「骨骼阈值」，例如骨松质可降到 150，纯皮质骨可升到 400。

## 打包为 Windows EXE

项目已配置 Electron 桌面封装（`electron/main.cjs` 在本地启动静态服务并打开窗口）。

```bash
npm install                                  # 安装 electron + electron-builder（会下载 Electron 运行时）
npm run dist:dir                             # 生成免安装目录版 dist-exe/win-unpacked/
npm run dist:portable                        # 生成单文件便携版 dist-exe/DICOM三维人体模型工具 1.0.0.exe
```

- **单文件便携版**：双击 `dist-exe\DICOM三维人体模型工具 1.0.0.exe` 直接运行，无需安装。
- **目录版**：`dist-exe\win-unpacked\DICOM三维人体模型工具.exe`（整个目录一起分发）。
- 使用中国镜像加速下载时可设 `ELECTRON_MIRROR` / `ELECTRON_BUILDER_BINARIES_MIRROR`（指向 npmmirror）。
